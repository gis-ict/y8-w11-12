Build your own project

Today you start your own program in VS Code. Do one step at a time, then press Next.

Your design brief: a program for a younger class. It can be a revision quiz, a unit converter or a text game. It must have a loop with an if inside it.

Today's six jobs

1Plan: pick a project. 5 min
2Build: make it work. 22 min
3Test: try 3 inputs. 8 min
4Fix: when you see an error. any time
5Modify: one change. 10 min
6Check: what you finished. 7 min

Teacher notes: start (3 min)

Students work individually. Each part has its own timer in the header: press ▶ when you start the part.

Before class: check that VS Code opens and runs a .py file on the lab computers (the ▶ Run Python File button, top right). If the Python extension is missing, students can type python quiz_v1.py in the Terminal.

Hour plan: Plan 5, Build 22, Test 8, Modify 10, Check 7, plus 3 to start and 5 spare. The Fix part is a reference to open any time.

    Teacher notes: Test (8 min)
    
   
    Insist on writing the expected result before running. A test that fails is a good result: it found a bug. Every project should have at least one normal, one boundary and one invalid test.
    
   
    The table saves in the browser on that computer only, so students should also copy it into their file.

    Fix it: the bug guide
    
    
    Look at the last line of the red error in the Terminal. Find it below and click it.
    
  
    Stuck? Do this
    1. Read the error. Which line?
    2. What did I expect? What did I get?
    3. Change one thing.
    4. Run it again.
    5. Still stuck? Ask a classmate, then the teacher.
